# 🎮 PUBG 편의 오버레이 (PUBG Convenience HUD Overlay)

배틀그라운드(PUBG) 플레이 중 **파밍 상황(필요 부착물 및 회복약 수량)**, **수류탄 쿠킹 타이머**, **자기장 페이즈**, **중앙 크로스헤어**를 게임 화면 위에 실시간으로 띄워주는 경량 투명 HUD 프로그램입니다.

> [!IMPORTANT]
> **면책 문구 (Disclaimer)**
> **"본 프로그램은 게임 메모리를 수정하거나 조작하지 않는 단순 독립 투명 윈도우 기반 유틸리티입니다."**
> 게임 클라이언트 바이너리, 프로세스 메모리, 네트워크 패킷을 일체 변조하거나 후킹하지 않으며 게임 내부 데이터에 접근하지 않습니다.

---

## 🛡️ 안티치트(배틀아이/자킨토스) 안전 및 기술 구조
- ❌ **게임 메모리(RAM) 읽기/쓰기 절대 없음** (`ReadProcessMemory`, `WriteProcessMemory` 0건)
- ❌ **DLL 인젝션 및 DirectX 훅 없음**
- ⭕ **Windows 네이티브 투명 오버레이(`WS_EX_TRANSPARENT` + `WS_EX_LAYERED`)**:
  - 게임 프로세스를 1바이트도 건드리지 않으며, 마우스 클릭이 뒤의 게임으로 100% 그대로 통과합니다 (에임/사격 방해 없음).
  - 디스코드(Discord) 오버레이, GeForce Experience 오버레이와 동일한 안전한 OS 레벨 윈도우 원리입니다.

---

## ⚙️ 배틀그라운드 인게임 필수 설정
> [!TIP]
> 게임 플레이 시에는 반드시 **'전체 창모드(Borderless Windowed)'**로 플레이하시면 기술적 충돌 없이 안전하게 사용하실 수 있습니다.
* **[환경설정] → [그래픽] → [디스플레이 모드]**: **`전체 창모드 (Borderless Windowed)`** (또는 `창모드`) 설정 필수!

## 🚀 실행 방법

### 방법 1: 가장 간편한 방법 (더블 클릭 - Zero-Config)
폴더 내의 **`run.bat`** 파일을 더블 클릭하여 실행합니다.
* **PC에 파이썬이 없어도 OK**: `run.bat`이 파이썬 미설치를 자동 감지하여 공식 Python 환경(tcl/tk 포함)을 무인 백그라운드 자동 설치한 후 즉시 실행합니다.
* **외부 pip 패키지 설치 필요 없음**: 100% Python 표준 라이브러리(`tkinter`, `ctypes`, `winsound`)로만 구현되어 있어 추가 패키지 설치 없이 즉시 구동됩니다.

### 방법 2: 파이썬 직접 실행
```bash
python pubg_overlay.py
```

## 🛠️ 커스터마이징 (`config.json`)
`config.json` 파일을 메모장으로 열어 단축키나 조준점 색상, 홀드 모드를 변경할 수 있습니다:

```json
{
  "hotkeys": {
    "loot_hud_hold": "VK_TAB",
    "crosshair_toggle": "VK_F1",
    "bluezone_advance": "VK_F2",
    "grenade_timer": "VK_F3",
    "preset_switch": "VK_F4"
  },
  "settings": {
    "loot_hud_hold_mode": true,
    "sound_enabled": true,
    "crosshair_style": "dot",
    "crosshair_color": "#00FF66",
    "crosshair_size": 4
  }
}
```
* `loot_hud_hold_mode`: `true`면 TAB 키를 누르고 있는 동안만 표시, `false`면 TAB 누를 때마다 켜고 끄는 토글 모드로 동작합니다.
